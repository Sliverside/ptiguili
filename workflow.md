Workflow :
- L'utilisateur joue à la roue -> il est débiter
- Il peut gagner diférents lot (plusieurs fois)
- L'utilisateur décide d'utiliser un lot
  - Il obtient un ticket (qrcode)
  - Le partenaire valide le ticket et l'utilisateur est débiter

- Le partenaire peu alors
  - créé un compte à rebours si nécessaire, les 2 interlocuteurs pouront alors le manipuler
  - passer le lot dans l'etat "used"
